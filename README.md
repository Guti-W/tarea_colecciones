# Tarea Práctica: Colecciones de Datos en Python

Este repositorio contiene la solución a la tarea práctica sobre el uso y manipulación de **colecciones de datos** (listas, tuplas, conjuntos y diccionarios) en Python.

---

## 📌 Descripción del Problema

El objetivo del proyecto es resolver una situación cotidiana mediante estructuras de datos eficientes. En este caso, desarrollé un **gestor / agenda de contactos telefónicos**, el cual permite:

- **Registrar nuevos contactos** asociando el nombre de una persona con su respectivo número telefónico.
- **Consultar números telefónicos** de manera directa mediante el nombre del contacto.
- **Listar todos los contactos** almacenados en el sistema.

---

## 🛠️ Estructura de Datos Utilizada

Para este programa utilicé un **Diccionario (`dict`)** de Python:

- **¿Por qué un diccionario?**  
  Porque organiza la información en pares `clave: valor`. En este caso, el nombre actúa como clave única (`key`) y el número de teléfono como su valor asociado (`value`).
- **Ventajas:**
  - Búsquedas rápidas y directas sin necesidad de recorrer elemento por elemento.
  - Evita duplicación de identificadores (no pueden existir dos contactos con la misma clave).
  - Facilidad para actualizar o modificar los datos asociados.
